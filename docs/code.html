_units_of() / _pack_sentences() rag_engine.py:124

这两个是 2026-11-14 加的帮手：先把段落拆成「不能切断的最小单位」，再把单位打包成卡片。切点因此只落在「条」与「条」之间、句号之后，不会再出现「…没收器具并视」这种半句开头。

124
_ARTICLE_SPLIT = re.compile(r"(?=第[一二三四五六七八九十百零\d]+条)")
「第 X 条」前面插一个切点。正则里的 (?=…) 是零宽断言：只标记位置、不吞掉文字，所以条文本身一个字都不会少。

def _units_of(para: str, chunk_size: int) -> list[str]:
    """把一段拆成「不被切断的最小单位」：优先条，条太长再按句子，句子还太长才按字符。

    这样保证切点只出现在条与条之间、句号之后，不会出现「…没收器具并视」这种半句。
    """
    units: list[str] = []
    for art in _ARTICLE_SPLIT.split(para):
        if not art.strip():
            continue
        if len(art) <= chunk_size:
            units.append(art)
            continue
        for sent in _SENTENCE_SPLIT.split(art):
            if not sent.strip():
                continue
            if len(sent) <= chunk_size:
                units.append(sent)
            else:  # 极端情况：单句超过块上限，只能硬切
                for off in range(0, len(sent), chunk_size):
                    units.append(sent[off : off + chunk_size])
    return units
拆单位，三层兜底：先按「条」拆；条太长再按句子拆；句子还超过上限（极端情况）才按字符硬切。前两层能命中，就绝不切句。
156–179
    units = _units_of(para, chunk_size)
    if not units:
        return []

    pieces: list[list[str]] = []
    buf: list[str] = []
    size = 0
    for unit in units:
        if buf and size + len(unit) > chunk_size:
            pieces.append(buf)
            tail: list[str] = []
            tail_size = 0
            for back in reversed(buf):
                if tail_size + len(back) <= overlap:
                    tail.insert(0, back)
                    tail_size += len(back)
                else:
                    break
            buf = tail[:]
            size = tail_size
        buf.append(unit)
        size += len(unit)
    if buf:
        pieces.append(buf)
打包：单位依次往筐里放，放不下就封筐；封筐时把最后几个整单位留作重叠。重叠也是整条/整句，所以边界两侧不会各剩半句。

创建 TF-IDF 计算器：analyzer 用 jieba 中文分词（因为中文词之间没空格），它还会额外加相邻两字的组合（2-gram），好处是专有词被切错也能补救，代价是词表变大、噪声变多；min_df=1 表示「只出现一次的词也保留」，norm='l2' 把每行长度归一化，避免长卡片天然分数高。

卡片曾经是按字数硬切的（已修）

旧版 12 段里有 3 段超过 280 字（293 / 304 / 299），被按 220 字一格硬切，于是第 4、8、10 张卡片从句子中间开始：-004 以「。」开头，-008 以「重警告处分；因此造成火情的，从重处理。」开头，-010 以「费为 20 元，挂失成功后原卡即时失效」开头——那种没头没尾的片段，检索到也没法用。

280 / 60 这两个数字分别管什么？

280 = 一张卡片最多多少字；60 = 相邻卡片重叠多少字（防止一句话正好被切在边界）。步长 = 280 - 60 = 220。
