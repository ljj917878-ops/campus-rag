## 现象

15 道评测题全部是"能直接回答"的正样本，全部得分 1.00，通过率 100%。这个评测门禁测不出任何东西——上面那个拒答门槛失效的缺陷，就是这么被漏掉的。

## 影响

- 门禁全绿，但系统实际会答非所问
- 没有负样本，就永远测不出"该拒答时有没有拒答"
- 评测看起来严格（有脚本、有指标），实际是自我安慰

## 期望行为

评测集扩到 30 题，分三组：

| 组别 | 数量 | 说明 |
|---|---|---|
| 正样本 | 15 | 现有一问一答，应命中且答案正确 |
| 负样本 | 8 | 与手册无关，应拒答 |
| 边界样本 | 7 | 多条款冲突、超出手册范围、问法模糊 |

## 验收标准

- [ ] 30 题全部有明确期望结果（答案关键词 / 应拒答）
- [ ] `evaluation.py` 按组输出指标：正例召回率、负例拒答率、边界组单列
- [ ] 门禁在负例拒答率 < 90% 时判定失败
- [ ] README 里贴出修复前后的对比表
